# Security policy

## Supported versions

Only the latest `main` branch and the newest tagged release are supported.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's
private security advisory feature for this repository, or contact the
maintainer privately through the GitHub profile `muhandis525`.

Do not include Wi-Fi passwords, BLE proof-of-possession values, device API
tokens, or TypeSafe API keys in reports, logs, screenshots, or pull requests.

The device HTTP API is currently intended for a trusted LAN only. Do not
expose it directly to the Internet.
